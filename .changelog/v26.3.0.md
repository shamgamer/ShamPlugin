# ShamPlugin 26.3.0 Changelog

## Breaking Changes

* Renamed the Java package and project domain from `win.shamserver` to `dev.shoam` / `shoam.dev`.
* Renamed `shamplugin.loginrewards` to `shamplugin.streaks.notify`. This permission now defaults to `true`.

## Added

* Added `debug: false` to line 2 of `config.yml` affects the new version support checker.
* Added support for `dev` and `snapshot` prerelease versions.
* Added support for versions prefixed with `v`, such as `v26.3.0`.
* Added initial build tests to help reduce manual testing.
* Added an optional `modify-last-claim` argument to `/sham streak set`:
  `/sham streak set <player> <value> [true/false]`

  When `true` (the default), the player’s last-claim time is updated.
* Added `/sham debug versionsupport`.
* Added compatibility checks at startup and through `/sham debug versionsupport`. That retrieves compatibility data from the project’s GitHub `versions.json` and reports whether the current Minecraft version is supported, known broken, or untested. The plugin also warns when the Minecraft version is no longer receiving ShamPlugin updates.
* `/sham debug alerts` now displays the Discord webhook name, channel ID, and server (guild) ID.
* Added `shamplugin.streaks.notify.<number>`, which subtracts unavailable rewards from the AxRewards reminder count. This is useful for excluding rank-gated rewards from reminders for players who cannot claim them.

## Removed

* Removed the old and obsolete `getBuildTime` function.
* Removed unused and broken "release-candidate" version extension ("rc" extension still exists).
* Removed large backup for alerts ignore feature.

## Changed

* Leaderboards now retain only the top entries in memory rather than loading the full leaderboard into memory.
* Leaderboard commands can now be used in the console.
* Replaced the bundled Jackson JSON library with provided Gson, reducing the final plugin JAR from ~2.4 MB to ~0.16 MB.
* Other small improvements and changes.
